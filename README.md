## Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **3D Graphics:** React Three Fiber / Three.js

## Features
- **3D Particle Hero:** An interactive, dynamic 3D particle system on the hero section.
- **Constellation Background:** A stunning space-like background connecting nodes.
- **Magnetic Cursor:** A custom cursor that magnetically snaps to interactive elements.
- **Keyboard Footer:** A unique isometric 3D keyboard for social links and footer navigation.

## Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/diptamnandi/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment Variables**
   - Copy the `.env.example` file to `.env`
   - Fill in your actual API endpoints (e.g., Formspree).
   ```bash
   cp .env.example .env
   ```

4. **Run the development server**
   ```bash
   npm run dev
   ```

## Build for Production
To build the project for production, run:
```bash
npm run build
```
To preview the production build locally:
```bash
npm run preview
```
